# Computation Description

The computation for this project will be **finding all positive factors of a given integer**.  
The system will take a single positive integer as input and determine every number that divides it evenly. 

For example, inputting the number "6" would result in the code outputting the numbers "1, 2, 3, 6", which are the factors of 6.
